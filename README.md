# داش كام الرحلة - Android V1.1

نسخة أندرويد APK مباشرة لتطبيق Dash Cam عربي.

## أهم التحديثات في V1.1

- إلغاء دائرة السرعة الكبيرة التي سببت إحساس أن الشاشة مقسومة.
- جعل شاشة الكاميرا هي العنصر الأساسي وبحجم كبير مناسب للهاتف.
- إبقاء المؤشرات بشكل بطاقات صغيرة أسفل الكاميرا.
- إصلاح مسار حفظ الفيديو على أندرويد بإضافة Native Bridge يحفظ نسخة مباشرة في الاستديو داخل مجلد:

`Movies/DashCamTrip`

- ما زال التطبيق يحتفظ بنسخة داخل تبويب الفيديوهات لعرضها أو مشاركتها.
- التقسيم الافتراضي أصبح كل دقيقة للتجربة حتى لا تثقل المقاطع على WebView.

## طريقة البناء

ارفع الملفات إلى GitHub ثم شغّل workflow:

`Build APK Direct`

سيتم إنشاء APK داخل:

`apk/dashcam-android-v1-1.apk`

## ملاحظة مهمة

هذه نسخة V1 تعتمد WebView ومحرك Canvas. إذا كان جهاز معيّن لا يدعم `canvas.captureStream` أو `MediaRecorder` داخل Android System WebView فسيظهر تنبيه واضح. النسخة الاحترافية التالية Native CameraX ستكون أقوى للتسجيل الطويل.
