# داش كام الرحلة - Android 4.4 Native

نسخة Java Native خفيفة لتطبيق Dash Cam عربي، تعمل من Android 4.4 (API 19) دون Flutter أو WebView.

## أهم المزايا

- تسجيل MP4 فعلي عبر Camera API وMediaRecorder.
- واجهة عربية احترافية خفيفة بلا عناصر متداخلة.
- كاميرا خلفية أو أمامية، وصوت اختياري مغلق افتراضياً.
- سرعة GPS وتاريخ ومدة تسجيل ظاهرة أثناء الرحلة.
- اختيار جودة 720p تلقائياً مع رجوع آمن لجودة أخف على الأجهزة القديمة.
- حفظ مباشر داخل:

`Movies/DashCamTrip`


## طريقة البناء

ارفع الملفات إلى GitHub ثم شغّل workflow:

`Build APK Direct`

سيتم إنشاء APK داخل:

`apk/dashcam-android-4.4.apk`

## ملاحظة مهمة

الختم المرئي يظهر فوق معاينة الكاميرا أثناء الاستخدام. التسجيل يعتمد ترميز الفيديو الأصلي للجهاز لضمان أقل استهلاك ممكن للذاكرة على Android 4.4.
