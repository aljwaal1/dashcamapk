# داش كام الرحلة - Android V1

نسخة أندرويد أولى لتطبيق Dash Cam بنفس روح نسخة الآيفون PWA، لكنها مغلفة داخل تطبيق Android APK.

## أهم الميزات

- كاميرا خلفية / أمامية.
- تسجيل فيديو من داخل التطبيق.
- طباعة التاريخ والوقت والسرعة والمسافة وأعلى سرعة ومدة الرحلة داخل الفيديو عبر Canvas.
- GPS لاحتساب السرعة والمسافة.
- تقسيم تلقائي للمقاطع: 1 / 3 / 5 دقائق.
- زر طوارئ لحماية المقطع الحالي.
- سجل فيديوهات داخل التطبيق.
- تنزيل / مشاركة / حذف / حماية المقاطع.
- جودة 720p أو 1080p.
- 24 أو 30 إطار.
- منع قفل الشاشة أثناء فتح التطبيق.
- عربي RTL.

## طبيعة الإصدار الأول

هذا الإصدار يستخدم واجهة WebView داخل أندرويد ويشغّل محرك التسجيل نفسه المستخدم في نسخة iPhone PWA. هذا يجعله سريع التجربة وسهل البناء، وفي نفس الوقت يحافظ على ختم الفيديو داخل التسجيل.

الإصدار الثاني المقترح لاحقًا يمكن أن يكون Native CameraX كاملًا مع Foreground Service وتسجيل أقوى في الخلفية.

## طريقة البناء على GitHub

1. ارفع هذا المشروع إلى مستودع GitHub جديد.
2. افتح تبويب Actions.
3. شغّل Workflow باسم: `Build APK Direct`.
4. بعد النجاح سيُضاف الملف:

```text
apk/dashcam-android-v1.apk
```

## الصلاحيات

التطبيق يطلب:

- الكاميرا.
- الموقع لعرض السرعة.
- الصوت فقط إذا فعّلت التسجيل بالصوت من الإعدادات.

## ملاحظات اختبار مهمة

- ثبّت الهاتف جيدًا قبل القيادة.
- لا تستخدم الشاشة أثناء القيادة.
- إذا لم تعمل الكاميرا على جهاز قديم، حدّث Android System WebView أو جرّب جهازًا أحدث.
- على بعض الأجهزة القديمة قد يكون دعم `MediaRecorder` داخل WebView محدودًا.
